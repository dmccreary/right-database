## Content Design Decisions

### Pedagogical Ordering
Chapters progress from concrete to abstract and from single-node to distributed:
- Ch 3–8: Database paradigms (relational → analytical → KV → column-family → document → graph)
- Ch 9–10: Distributed systems theory foundations (CAP, ACID)
- Ch 11–13: Distributed engineering (scaling, NewSQL, HA)
- Ch 14–15: Cross-cutting capabilities (vector search, LLM embeddings)
- Ch 16: Synthesis (ATAM-based selection, polyglot persistence)

### ATAM Integration
Every chapter closes with an "ATAM Lens" section that identifies sensitivity points and tradeoff points specific to that paradigm, tying chapter content back to the course's analytical framework.

### MicroSim Library Conventions
- **p5.js:** Used for all custom interactive visualizations (timelines, simulators, calculators, animators)
- **vis-network:** Used for all graph/network diagrams (property graphs, knowledge graphs, architecture diagrams)
- Node color conventions (vis-network): entity = `#4682B4`, property = `#E65100`, index = `#28a745`, aggregate = `#6f42c1`, external = `#6c757d`
- All MicroSims specify CANVAS_HEIGHT in the first 15 lines for iframe height sync tooling

### Mascot Rules Applied
- `mascot-welcome`: first admonition, chapter open only
- `mascot-celebration`: last admonition, chapter close only
- Intermediate poses used: `mascot-tip`, `mascot-warning`, `mascot-thinking`, `mascot-encourage`
- Max 5 admonitions per chapter; none placed back-to-back
- All images: `<img src="../../img/mascot/<pose>.png" class="mascot-admonition-img">`
